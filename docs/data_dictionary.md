# Data Dictionary

This dictionary describes the analysis-ready dataset generated by `src/data_cleaning.py`.

**Dataset output:** `data/processed/trappers_loop_daily_features.csv`

| Column | Type | Description |
| --- | --- | --- |
| date | datetime | Calendar date for the daily record. |
| daily_total_volume | float | Sum of hourly traffic volume across both lanes for the full day. |
| morning_peak_volume | float | Maximum hourly traffic volume between 7:00 and 8:59 AM. |
| morning_window_avg_volume | float | Mean hourly traffic volume in the 7:00-8:59 AM window. |
| morning_window_total_volume | float | Sum of hourly traffic volume in the 7:00-8:59 AM window. |
| day_of_week | string | Day name derived from `date` (e.g., Monday, Saturday). |
| is_weekend | boolean | `True` when `date` is Saturday or Sunday. |
| holiday_name | string | Name of observed U.S. federal holiday if the date matches one; otherwise null. |
| is_federal_holiday | boolean | `True` when `date` is an observed U.S. federal holiday. |
